# War Mod — военный мод для Minecraft 1.20.1 (Forge)

Полноценный «военный» мод: 32 модели оружия с отдачей и перезарядкой, 5 единиц техники с физикой
движения, боты с ИИ и приказами, команды/фракции, отдельное измерение «Поле боя» с ночным небом,
туманом и процедурным эмбиентом, а также собственный экран смерти «ПОГИБ.».

* Mod ID: `warmod`
* Пакет: `com.warmod`
* Версия: 1.0.0
* Minecraft: **1.20.1**, Forge **47.4.8** (47.4.x), Java **17**
* Обязательная зависимость: **GeckoLib 4.8.5** (`geckolib-forge-1.20.1-4.8.5.jar`)

---

## 1. Сборка из исходников

```bash
git clone https://github.com/squezech-cmd/war_mod_minecraft.git
cd war_mod_minecraft
./gradlew build          # Windows: gradlew.bat build
```

Готовый мод: `build/libs/warmod-1.0.0-mc1.20.1.jar` (файлы `*-sources.jar` не нужны).

Требуется JDK 17 (например, Temurin 17). Сборка автоматически проверяется в GitHub Actions
(`.github/workflows/build.yml`): сначала `./gradlew build`, затем запуск выделенного сервера
(`./gradlew runServer`) — проверка загрузки мода и создания измерения `warmod:battlefield`.

## 2. Установка

1. Установите Forge 47.4.x для Minecraft 1.20.1.
2. В папку `mods/` положите:
   * `warmod-1.0.0-mc1.20.1.jar`
   * `geckolib-forge-1.20.1-4.8.5.jar` (обязательно, без него мод не запустится)
3. Запустите игру → `Моды` → в списке должен быть «War Mod».

## 3. Быстрый старт

```
/warmod join                       — телепорт на Поле боя (своя точка появления команды)
/warmod team create <имя> <фракция> — создать команду (фракции: alpha / bravo)
/warmod spawn bots 4               — заспавнить 4 ботов своей команды рядом с собой
/warmod spawn vehicle tank         — заспавнить технику (armored_car_1, armored_car_2, plane, helicopter, tank)
/warmod order follow               — приказ своим ботам (follow / hold / attack / retreat)
/warmod leave                      — вернуться в обычный мир
/warmod status                     — диагностика (уровень, чанки, сущности; только для операторов)
```

Также работает предмет **«Рация командира»** (ПКМ — GUI: спавн солдата, приказ, смена оружия, число ботов).

## 4. Возможности

### Оружие (32 единицы)
Автоматы: AK-47, AK-74, M4A1, M16A4, SCAR-L, AUG, G36C ·
ПП: MP5, MP7, UMP45, P90 ·
Снайперские: AWP, M24, Barrett M82, SVD ·
Дробовики: Remington 870, Saiga-12, SPAS-12 ·
Пистолеты: Glock 17, Desert Eagle, M1911, USP ·
Пулемёты: M249, PKM, Minigun ·
Гранатомёты: RPG-7, M320 ·
Ближний бой: нож, мачете ·
Метательное: граната Ф-1, дымовая граната, C4.

Для каждого оружия: своя GeckoLib-модель (`geo/*.geo.json`), анимации `idle/draw/fire/reload/ads/sprint`,
иконка 32×32, параметры (урон, разброс, дальность, отдача по вертикали/горизонтали, ёмкость магазина,
скорость перезарядки, режим огня, тип прицела, тип патронов) и своя текстура прицела ADS.

* Стрельба: серверный raycast (`ProjectileUtil.getEntityHitResult`), урон/убийство считаются на сервере.
* Клиент: трассер, вспышка ствола, отдача камеры, звук выстрела, зум/замедление при ADS, оверлей прицела.
* Перезарядка — клавиша **R**: анимация + звук + расход патронов из инвентаря + таймер.
* Смена режима огня — **B** (авто / одиночный / очередь).
* Боеприпасы отдельными предметами: 5.56, 7.62, 9 мм, .50, патроны 12 калибра, 40 мм, ракеты, снаряды.
* Блок **Ящик с патронами** (ставится, открывается, крафтится).

### Техника (5 единиц)
| Техника | Управление | Особенности |
|---|---|---|
| Бронеавтомобиль 1 / 2 | W/S — газ/тормоз, A/D — плавный руль, Пробел — ручник | броня, 3 места, стрельба из окна, 3-е лицо |
| Самолёт | W/S — тангаж, A/D — крен, мышь — рыскание, Shift — форсаж | шасси, автопилот по высоте, взлёт/посадка |
| Вертолёт | W/S — шаг винта (вертикально), A/D — рыскание, мышь — наклон | вертикальный взлёт, стрельба в бок |
| Танк | W/S — газ, A/D — корпус, мышь — башня | раздельные корпус/башня, снаряд со взрывом, перезарядка, следы гусениц |

У всей техники: запас топлива (100 % при спавне), здоровье, визуальные повреждения, места
водителя/пассажира/стрелка, зацикленный звук двигателя, звуки выстрелов и попаданий,
посадка/высадка по ПКМ предметом-ключом, камера от первого лица у водителя.

### Боты и команды
* `SoldierEntity` (PathfinderMob + GeckoLib): анимации `idle/run/aim/shoot/reload/death`, случайное оружие из пула.
* Поведение: поиск ближайшего врага, стрельба при прямой видимости с разбросом и задержкой (не «снайперы»),
  перезарядка, укрытия, патрулирование, выполнение приказов: **follow / hold / attack / retreat**.
* Команды: создание, приглашение игрока, вступление, счёт убийств, своя точка спавна, цвет фракции.
* Волны вражеских ботов — серверный тикер (период задаётся в конфиге).

### Измерение «Поле боя»
* `warmod:battlefield` — пустыня/разрушенный город, фиксированное ночное время (18000), биом `warmod:ruined_city`.
* Тёмное небо и туман (`DimensionSpecialEffects`, цвет неба `0x1a1a20`) — отключается в конфиге.
* Каждые 10–30 с серверный тикер проигрывает всем игрокам в измерении случайный эмбиент:
  далёкая стрельба, пролёт самолёта/дрона, сирена, взрывы.
* Тёмная фоновая музыка (зацикленный трек `music_battlefield`).

### Смерть
* Свой экран смерти вместо ванильного: тёмный фон, крупное «**ПОГИБ.**», счётчик убийств/возрождений «200.»,
  кнопки «**Вернуться в бой**» (возрождение на точке команды с отсчётом 3 с) и «**Покинуть поле боя**»
  (телепорт в обычный мир).
* Труп-сущность `soldier_corpse` — падение на колени (анимация `death`), тело остаётся на поле боя.

## 5. Управление

| Действие | Клавиша |
|---|---|
| Выстрел | ЛКМ (ПКМ у гранат/метательного) |
| Прицеливание (ADS) | ПКМ (удерживать) |
| Перезарядка | **R** |
| Смена режима огня | **B** |
| Посадка/высадка из техники, вход | **ПКМ** |
| Смена камеры техники | **V** |
| Аварийная высадка | **X** |
| Газ / тормоз | **W / S** |
| Поворот / крен | **A / D** |
| Ручник / форсаж | **Пробел / Shift** |
| Рация командира | ПКМ предметом |
| Меню мода (клавиши) | Настройки → Управление → «War Mod» |

Все клавиши переназначаются в настройках. Движение и стрельба обрабатываются сервером:
клиент отправляет пакеты (`ShootPacket`, `ReloadPacket`, `VehicleControlPacket`, `TeamPacket`, `OrderPacket`),
сервер проверяет кулдауны, патроны, топливо и наносит урон.

| `vehicleFuelDrain` | расход топлива техники |
| `friendlyFire` | урон по своим |

## 7. Как проверить (чек-лист)

1. Игра запускается, мод есть в списке модов, ошибок в логе нет.
2. `/warmod join` → вы на Поле боя: ночь, тёмное небо, туман, периодически слышны выстрелы/сирена.
3. Взять AK-47 из креативной вкладки «War Mod» → ЛКМ стреляет, есть трассер, отдача, звук; **R** — перезарядка, **B** — режим огня.
4. ПКМ — прицел, движение замедлено, появляется прицельная сетка.
5. `/warmod spawn vehicle tank` → ПКМ по танку: посадка, W/S — движение, мышь — башня, ЛКМ — выстрел, топливо убывает.
6. `/warmod team create Alpha alpha`, `/warmod spawn bots 3` → боты идут за вами, стреляют по врагам, **R**-перезарядка видна в анимации.
7. `/warmod order hold` / `attack` / `retreat` → боты меняют поведение.
8. Умереть → экран «ПОГИБ.» с двумя кнопками; «Вернуться в бой» — отсчёт 3 с и респавн на точке команды.

## 8. Что сгенерировано процедурно (заменить на финальные ассеты)

Все звуки, текстуры и часть моделей созданы скриптами из `tools/` и являются **плейсхолдерами**.
Формат и пути финальные — достаточно заменить файлы, код менять не нужно.

**Заменить:**

| Что | Где | Скрипт |
|---|---|---|
| Все 35 звуков (выстрелы, перезарядка, двигатели, эмбиент, музыка, UI) | `assets/warmod/sounds/*.ogg` | `tools/gen_sounds.py` |
| Модели оружия (32) | `assets/warmod/geo/<id>.geo.json` | `tools/gen_models.py` |
| Анимации оружия | `assets/warmod/animations/<id>.animation.json` | `tools/gen_models.py` |
| Иконки оружия/патронов (32×32) | `assets/warmod/textures/item/*.png` | `tools/gen_models.py`, `tools/gen_resources.py` |
| Текстуры прицелов ADS (19) | `assets/warmod/textures/gui/scope/*.png` | `tools/gen_models.py` |
| Модели/анимации/текстуры ботов и техники | `assets/warmod/geo|animations|textures/entity/` | `tools/gen_entities.py` |
| Текстуры предметов-ключей, ящика, UI | `assets/warmod/textures/item|block` | `tools/gen_resources.py` |
| Тексты интерфейса | `assets/warmod/lang/ru_ru.json`, `en_us.json` | `tools/gen_resources.py` |

Перегенерация: `python3 tools/gen_models.py && python3 tools/gen_entities.py && python3 tools/gen_sounds.py && python3 tools/gen_resources.py`
(нужны `pillow`, `numpy`, `soundfile`). Проверка целостности ассетов: `python3 tools/validate_assets.py`.

## 9. Известные ограничения

* Графика и звук проверены только статически: в CI выполняется сборка и запуск **выделенного сервера**;
  клиентский запуск (рендер, GeckoLib-анимации в кадре) в CI без GPU не тестировался — проверяйте вручную.
* Текстуры и звуки — процедурные плейсхолдеры (см. раздел 8).
* Трассеры/вспышки и следы гусениц — упрощённые частицы, не отдельные 3D-эффекты.
* Боты стреляют рейкастом с разбросом, без полноценного баллистического расчёта и без сложного pathfinding по укрытиям
  (укрытие выбирается по ближайшему блоку-препятствию).
* Самолёт и вертолёт используют упрощённую модель полёта (без честной аэродинамики), автопилот держит высоту по таймеру.
* Фоновая музыка зацикливается перезапуском SoundInstance, стык трека может быть слышен.
* Мультиплеер: урон и топливо считаются сервером; при высоком пинге возможна рассинхронизация отдачи (косметика).
* C4 детонирует по таймеру после установки; проводного подрыва нет.

```
├── Warmod.java                 — точка входа, регистрация всего
├── registry/                   — ItemRegistry, EntityRegistry, SoundRegistry, BlockRegistry, CreativeTabRegistry
├── item/                       — GunItem (абстрактный), GunRegistry, GunHandler, AmmoItem, SpawnerItem, RadioItem, ...
├── entity/                     — SoldierEntity, VehicleBase, ArmoredCar, Plane, Helicopter, Tank, WarProjectile, ShellEntity, ...
├── network/                    — NetworkHandler, ShootPacket, ReloadPacket, VehicleControlPacket, TeamPacket, OrderPacket, ...
├── team/                       — TeamManager, Team, TeamSavedData, TeamCommands, Faction
├── client/                     — KeyBindings, DeathScreenWar, RadioScreen, BattlefieldSky, ClientSkyAndFov, renderer/, model/
├── world/                      — DimensionRegistration, BattlefieldChunkGenerator, AmbientSoundHandler
└── config/                     — WarConfig
src/main/resources/assets/warmod/   — models, textures, geo, animations, sounds, lang (ru_ru, en_us)
src/main/resources/data/warmod/     — recipes, tags, dimension, dimension_type, worldgen/biome
tools/                              — генераторы ассетов и валидатор
```
